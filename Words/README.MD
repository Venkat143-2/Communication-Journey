# 📚 Words

The `Words/` folder contains the vocabulary I learn throughout my communication journey.

The goal is **not to memorize difficult English words**.

The goal is to learn words that I can:

* Understand
* Remember
* Use correctly
* Use naturally
* Use while speaking and writing

> **A word is truly learned when I can use it correctly without forcing it.**

---

# 🎯 Goal

Learn **20 useful words every week** and gradually increase my active vocabulary.

```text
20 words / week
      ↓
Learn meaning
      ↓
Understand usage
      ↓
Create sentences
      ↓
Use in speaking
      ↓
Use in writing
      ↓
Review
      ↓
Become active vocabulary
```

# 📝 Word Format

Every word should contain more than just its meaning.

Use this structure:

```markdown
## 1. Reluctant

**Part of Speech:** Adjective

**Meaning:** Unwilling or hesitant to do something.

**Pronunciation:** /rɪˈlʌktənt/

**Example:**
He was reluctant to speak in front of the audience.

**My Sentence:**
I was reluctant to ask my professor for help.

**When to Use:**
Use this word when someone does not want to do something
or is hesitant about doing it.

**Synonyms:**
- Hesitant
- Unwilling

**Antonyms:**
- Willing
- Eager

**Status:** Learning
```

# 🧠 What to Learn for Each Word

For every new word, try to learn:

### 1. Word

```text
Reluctant
```

### 2. Part of Speech

```text
Adjective
```

Knowing the part of speech helps you understand where the word can appear in a sentence.

### 3. Meaning

Understand the meaning in **simple English**.

Avoid memorizing complicated dictionary definitions.

### 4. Pronunciation

Learn how the word is actually pronounced.

### 5. Example

Understand how another person naturally uses the word.

### 6. My Sentence

Create your own sentence.

This is extremely important.

> **Don't only understand the example. Create your own example.**

### 7. When to Use

Understand the situation where the word is appropriate.

### 8. Synonyms and Antonyms

Learn a few related words when useful.

Don't try to memorize huge lists.

# 🔥 Active vs Passive Vocabulary

There are two important levels of vocabulary.

## Passive Vocabulary

I can understand the word when:

* Reading
* Listening
* Watching videos

But I don't naturally use it.

Example:

> I understand the word **"reluctant"**, but I never use it myself.

---

## Active Vocabulary

I can naturally use the word while:

* Speaking
* Writing
* Explaining
* Having conversations

Example:

> "I was reluctant to join the meeting because I wasn't prepared."

The goal of this repository is to gradually convert:

```text
Passive Vocabulary
       ↓
Practice
       ↓
Active Vocabulary
```

# 📊 Word Status

Each word can have a status.

```text
🆕 New
📖 Learning
🔄 Reviewing
✅ Known
🔥 Active
```

Example:

```markdown
**Status:** 🔄 Reviewing
```

### Meaning

**🆕 New**

Just introduced.

**📖 Learning**

I understand the basic meaning but cannot use it confidently.

**🔄 Reviewing**

I have learned it but need more practice.

**✅ Known**

I can understand and remember the word.

**🔥 Active**

I can naturally use the word while speaking or writing.

---

# 🔄 Review System

Learning a word once is not enough.

Use spaced review.

```text
Day 1  → Learn
Day 2  → Review
Day 4  → Review
Day 7  → Review
Day 14 → Review
Day 30 → Review
```

The exact schedule can change.

The important principle is:

> **Review words before you forget them.**

# 🗣️ Use Words in Speaking

New vocabulary should enter the `Learning/Speaking/` section.

For example:

```text
New word:
Reluctant

Speaking practice:
"I was reluctant to participate in the event,
but eventually I decided to join."
```

This helps convert vocabulary from passive knowledge into active vocabulary.

---

# ✍️ Use Words in Writing

New vocabulary should also appear naturally in the `Learning/Writing/` section.

Example:

```text
Today I was reluctant to start my project because
I felt that I didn't know enough about the technology.
```

The goal is **natural usage**.

Do not force a new word into every sentence.

# 🧩 Context Is More Important Than Memorization

Don't learn:

```text
"Implement = put into effect"
```

and stop there.

Understand how it is used:

```text
implement a plan
implement a solution
implement a strategy
implement a feature
implement a policy
```

This teaches **natural word combinations**.

---

# 🔗 Collocations

A collocation is a combination of words that commonly appear together.

For example:

```text
make a decision
make progress
take responsibility
take action
strong argument
deep understanding
```

Learning words together with their common combinations makes English sound more natural.

---

# 🚫 Don't Learn Words Just Because They Are Difficult

The goal is not:

> "I know 5,000 complicated words."

The goal is:

> "I can communicate clearly using the right words."

Prefer words that are:

* Useful
* Common
* Relevant to daily life
* Useful for academics
* Useful for professional communication
* Useful for conversations
* Useful for expressing emotions and opinions

# 🧪 Weekly Vocabulary Test

At the end of each week, test the 20 words.

Test different abilities.

### Test 1 — Meaning

```text
What does this word mean?
```

### Test 2 — Recognition

```text
Which word fits this sentence?
```

### Test 3 — Usage

```text
Create your own sentence.
```

### Test 4 — Speaking

Use the word while speaking.

### Test 5 — Recall

Try to remember the word without looking at the list.
